## Summary

`charly candy params` carried its own **concat → header → temp CUE write → `cue exp gengotypes` → retag** sequence, while spec's own generator carried a **second copy of the same sequence** — two implementations of one behaviour, free to drift.

[`spec/schemaparams`](https://github.com/opencharly/spec/pull/214) (tag **`v0.2026281.933`**) is that pipeline as **one public entry point**, so the copy is **deleted** here. `generateParams` is now three lines around:

```go

```

**The deletion IS the proof.** A wrapper that kept its own sequence would have been a **third copy wearing the name of a fix**, so the diff is net **negative**:
